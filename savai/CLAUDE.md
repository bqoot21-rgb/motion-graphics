# 채널 규칙

## 기본 설정
- 언어: 대본, 내레이션, 자막 모두 영어
- 대본 확인 단계에서는 영어 대본 옆에 한국어 번역을 함께 보여줄 것
  (script.md는 영어만, 번역은 script_ko.md에 따로 저장)
- 해상도: 1920x1080, 24fps
- 영상 제작은 lemo-opuscar 스킬로 함
- 내레이션: Kokoro TTS로 자동 생성. 목소리는 채널 전체에서 하나로 고정 (voice 설정은 아래)
  내 목소리 파일이나 음악 자료는 따로 없으니 묻지 말고 진행할 것
- Kokoro 목소리: bm_george (속도 0.9 전후)
- 효과음은 내레이션보다 약 12dB 낮게 (내레이션 구간)

## 스타일 규칙
- 메인: 내 스타일 "Crayon Case" → 인물, 관계, 사건 장면 등 이야기의 대부분
- Projection on White Model → 건물 구조, 방 배치, 사람들의 위치
- Satellite Briefing → 지역 소개, 이동 경로, 도주·탈출 경로
- Liminal Found Footage → 빈 공간, 사건 이후의 장소, 챕터 전환 (한 번에 10초 이내)
- 메인 스타일이 전체의 60% 이상이 되게 할 것

## 모든 스타일 공통
- 강조색은 핫핑크(#FF1493) 하나만. 다른 강조색 쓰지 말 것
- 자막: 하단 중앙, 흰 글씨, 단정한 고딕체, 모든 장면 동일
- 내레이션 목소리와 배경음 톤은 영상 전체에서 통일
- 다른 스타일 장면 안에 크레용 그림을 등장시켜 연결할 것
  (예: 화이트 모형 벽에 붙은 아이 그림, 위성 지도 위에 핫핑크 크레용으로 그린 경로)

## 대본 구조
1. 훅 (약 1분): 날짜·시간·장소로 한 장면 시작 → 가장 충격적인 결과 예고 → "어떻게?" 질문
2. 발각 과정
3. 범인의 배경
4. 지배와 범행 방식
5. 수사와 재판
6. 에필로그: 덜 알려진 추가 사실 + 여운 있는 마지막 문장
- 구간이 바뀔 때마다 "그렇다면 ○○는 왜?" 같은 질문으로 다시 붙잡기
- 존댓말, 차분하고 담담한 조사보도 톤. 과장된 감탄이나 자극적 표현 금지

## 반드시 지킬 것
- 판결이 확정된 사건, 또는 용의자가 특정·공개되지 않은 미제 사건만 다룸
  (미제 사건에서는 용의자를 추정하거나 특정 인물을 암시하지 않음. 분석·의견은 "사실이 아님"을 밝히고 말할 것)
- 모든 사실은 sources.md에 출처 링크와 함께 기록. 출처 없는 내용은 대본에 넣지 않음
- 폭력·학대는 직접 그리지 말고 암시로 표현 (닫힌 문, 빈 방, 남겨진 물건 등)
  내레이션은 보도된 사실대로 말해도 되지만, 화면은 항상 부드럽게
- 피는 항상 핫핑크로 (Crayon Case 규칙)
- 피해자를 귀엽게 그리거나 희화화하지 말 것
- 실제 사진이나 뉴스 영상은 쓰지 않음. 전부 코드로 그림

## 작업 순서 (멈춤 지점 반드시 지킬 것)
1. 사건 조사 → sources.md 작성, 대본 → script.md 작성
   → **멈추고 내 확인 기다리기**
2. 대본 확정 후 챕터 4~5개로 나누고, 챕터별 핵심 장면 스토리보드를 보여줄 것.
   각 장면마다 어떤 스타일을 쓸지와 이유를 함께 표시
   → **멈추고 내 확인 기다리기**
3. 확인 받으면 챕터별로 영상 제작 (챕터마다 따로 만들어서 chapters/ 에 저장)
4. 전부 끝나면 ffmpeg로 이어붙여 final.mp4 생성
   → **최종 확인 요청**
